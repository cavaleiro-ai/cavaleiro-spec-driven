# Support

## How to get help

Please search existing [issues](https://github.com/cavaleiro-ai/cavaleiro-spec-driven/issues) and [discussions](https://github.com/cavaleiro-ai/cavaleiro-spec-driven/discussions) before you create a new one.

- Read the [README](./README.md) to get started, or the [Portuguese guide](./docs/cavaleiro/GUIA-PT-BR.md) (*guia em português*).
- Read the [Spec-Driven Development methodology](./spec-driven.md) for the full process.
- Ask questions about using Cavaleiro Spec Driven or Spec-Driven Development in [GitHub Discussions](https://github.com/cavaleiro-ai/cavaleiro-spec-driven/discussions).
- Open a [GitHub issue](https://github.com/cavaleiro-ai/cavaleiro-spec-driven/issues/new/choose) to report a bug or request a feature.
- Report vulnerabilities privately, as described in the [security policy](./SECURITY.md).

## Project status

**Cavaleiro Spec Driven** is maintained by [Cavaleiro AI](https://github.com/cavaleiro-ai). Support is best effort.
